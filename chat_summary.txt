# Database

We'll convert your SQL into SQLAlchemy Models.

Instead of writing SQL like

```sql
SELECT * FROM expenses;
```

We'll write

```python
Expense.query.all()
```

This is called an **ORM (Object Relational Mapper)**.

# Authentication

Instead of plain passwords

```
123456
```

We'll store

```
pbkdf2:sha256:600000....
```

using

```python
generate_password_hash(password)
```

Login

```python
check_password_hash(hash,password)
```

This is much more secure.

# Folder Explanation

## app.py

This is the main application.

It starts Flask.

Registers routes.

Connects database.

Runs server.

Equivalent to

```
main()
```

in C++.

## Models

These represent database tables.

Example

```python
class Expense(db.Model):

    id=db.Column(db.Integer,primary_key=True)

    amount=db.Column(db.Float)

    category=db.Column(db.String(50))

    date=db.Column(db.Date)
```

Every object

```python
Expense(...)
```

becomes one row inside MySQL.

---

## Routes

Routes decide

"If user opens this URL, what should happen?"

Example

```python
@app.route("/dashboard")
```

means

```
localhost/dashboard
```

will execute that function.

↓

AI Extraction

Notification:

For your **1-week MVP**, we can process documents synchronously because it's simpler and easier to understand. But we'll design the code so that switching to background processing later only requires changing the processing mechanism—not rewriting the business logic.

## Relationships

- **USERS → DOCUMENTS** = One-to-Many
- **USERS → REPORTS** = One-to-Many

This database is normalized to **Third Normal Form (3NF)** and provides a clean foundation for the college project while remaining extensible for future features such as inventory, GST analytics, multi-company support, and team collaboration without major schema changes.
